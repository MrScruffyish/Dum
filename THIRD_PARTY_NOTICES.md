It uses the following libraries, which have their own (GPL-compatible) licences.

| Library | Used for | How it is included | Licence |
|---------|----------|--------------------|---------|
| ENet 1.3.18 | networking | source code in `third_party/enet`, built into the game | MIT |
| SDL2 | window, input, sound | Linux: system library. Windows package: `SDL2.dll` | zlib |
| SDL2_image | loading PNG replacement art | Linux: system library. Windows package: `SDL2_image.dll` | zlib |
| stb_image, QOI, NanoSVG | image decoders inside `SDL2_image.dll` | Windows package only | MIT / MIT / zlib |
