# Dum item definitions.
#
# kind:    weapon, armor, helm, ring, amulet, light, food, potion, scroll, fuel, gold, quest, wand, rod
# Bonuses while worn (any wearable item): str dex con int wis (+N), tohit, todam, armor,
#   light (extra radius), speed (+1 = 10% faster), stealth, search, slowdigest (% less
#   hunger), regen (% faster healing), spellpower, resist = fire, cold, ...
# Weapons: brand = fire | cold | holy | poison (damage element; cold slows, holy x2 vs undead).
# Potions: heal, mana, gainstat = str|dex|con|int|wis (permanent +1), restore = yes (drained
#   stats), curepoison = yes, spell = <id> (casts it, like a scroll). Food can also heal.
#   Any healing cures poison.
# artifact = yes: unique, only one exists per game (never sold in shops).
# Keys: kind = key, keycolor = red|blue|green|yellow - opens doors with that colour of lock
#   (used up). The dungeon places a key on every level that has such a door.
# Chests: kind = chest. 'chest' is placed closed (treasure, empty or trapped - decided when
#   the level is made), 'chest_open' is what is left after opening one.
# everburning = yes: a light that never runs out.
# sprite:  floor picture (dagger sword mace axe staff bow armor robe torch lantern
#          ration apple meat potion scroll flask gold amulet tome chalice wand rod)
# Wands:   spell, charges = MIN-MAX (each use takes one). Rods: spell, recharge = seconds.
#          Anyone can use them; the class 'device' skill lowers the failure chance
#          (deeper items fail more often) and adds to their power.
# Weapons: dice, tohit, cooldown (seconds), range (tiles), arc (auto-aim cone, degrees),
#          finesse = uses DEX instead of STR, ranged = shoots arrows/stones.
# depth/rarity control random generation (rarity 0 = never placed randomly,
# higher = more common).
