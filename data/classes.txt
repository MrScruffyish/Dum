# Dum character classes.
#
# str/dex/con/int/wis: base stats (a little randomness is added at creation).
# hitdie:  hit points gained per level = 1d<hitdie> + CON modifier.
# mana / manaperlevel: spell points (plus cast stat modifier per level).
# melee/ranged/magic: skill bonus to hit and spell power.
# search: finding secret doors. stealth: monsters wake up slower. disarm: picking locks.
# device: skill with wands and rods (fewer failures, more damage).
# spells: spell ids, optionally "spell:level" to override when the class learns it.
#         Abilities (warriors) are spells too - see spells.txt.
# items: starting equipment (first weapon/armor/light found is equipped).
