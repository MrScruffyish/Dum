# Dum difficulty levels. The host (or dedicated server) picks one; it applies to everyone
# and is stored in the save. Shown in the main menu in this order. Add your own!
#
# monster_damage / monster_hp / monster_speed: multipliers
# monster_tohit: added to monster attack rolls
# alertness:     how quickly sleeping monsters notice you (multiplier)
# extra_groups:  more (or fewer, negative) monster groups per level
# hunger / fuel: how fast food and light run out (multipliers)
# respawn:       seconds until a dead player gets back up (while someone lives)
# party_wipe:    restart = the whole party dead starts a new game; revive = everyone gets up
# xp / gold:     multipliers for experience and gold found
