# Dum monster definitions.
#
# name/plural: plural defaults to name + "s"
# sprite:  rat bat humanoid caster skeleton spider beast big ghost blob
# color/color2: body / eye (accent) color, hex RRGGBB
# hp, dmg: dice.  ac: armor class (players roll d20 + bonus >= ac to hit).
# speed: tiles per second.  sight: how far it notices players (tiles).
# sleep: % chance to start asleep.  group: e.g. 2-4 spawns a pack.
# spell + spellrate: ranged attack and how often (per second) it is used.
# boss = yes: placed by quests only, never randomly.
# Abilities: steals = yes (takes gold, then teleports away),
#   regen = N (hit points per second), erratic = N (% of time flying about randomly),
#   drainlight = yes (hits burn your light's fuel), explode = <spell> (when it dies),
#   resist = fire, cold... (half damage), vulnerable = ... (double damage),
#   poison = N (its hits poison you for N seconds), drain = str|dex|con|int|wis (its hits
#   may drain that stat until restored), blink = yes (teleports around you while fighting),
#   invisible = yes (a faint shimmer: you can only aim at it up close, or while detecting),
#   summon = <monster id> or kin, summonrate = chance per second (calls 1-2 for help, at
#   most 3 times; the summoned monster must be defined earlier in the file).
#   breeds = yes: multiplies slowly, one copy every 'breedtime' seconds (default 30) while
#   awake, never more than 6 close together or 20 of a kind on a level.
# More sprites: snake worm eye imp elemental golem dragon
